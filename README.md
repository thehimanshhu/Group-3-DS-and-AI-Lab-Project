# Deepfake Voice Detection for Indian Languages

A deep learning model that tells whether a speech clip is spoken by a **real person** or **generated by AI**, in **English, Hindi, Tamil and Telugu**.

> DSAI Lab Project · IIT Madras BS Degree

## Why

AI tools can now copy a voice from a few seconds of audio, and cloned voices are used in scam calls. Most existing detectors are trained and tested only on English speech. We test how well detection works for Indian languages, new voice-generation tools and phone-quality audio.

## Approach

- **Data:** Real speech from Kathbath and ASVspoof 2019; fake speech from IndicSynth plus our own clips generated with Indic Parler-TTS, IndicF5 and MMS-TTS.
- **Model:** Fine-tuned XLS-R 300M speech encoder with a small classification head, compared against a spectrogram CNN and AASIST-L.
- **Evaluation:** Equal Error Rate (EER) on in-domain, cross-language, unseen-generator, In-the-Wild and phone-channel tests.
- **Demo:** Gradio web app on Hugging Face Spaces and a Telegram bot, returning a real / AI verdict, a confidence score and a saliency view.

## Milestone 5: Evaluation and Analysis

- **Report:** [Milestone-5.md](milestones/Milestone-5/Milestone-5.md) · [Presentation](milestones/Milestone-5/Milestone-5-presentation.pdf) · [Worklog](milestones/Milestone-5/worklog.md) · [AI usage disclosure](AI-usage-disclosure.md)
- **Model weights and data manifest:** [Hugging Face Hub](https://huggingface.co/TarikaHedaoo/indic-deepfake-voice-detection) (final, default and baseline models; CC-BY-NC-4.0)
- **Notebooks** (saved with their outputs):
  - [`01_full_test_sets.ipynb`](notebooks/Milestone-5/01_full_test_sets.ipynb): the full test sets (118,295 clips), merged manifest and leakage checks
  - [`02_errors_and_calibration.ipynb`](notebooks/Milestone-5/02_errors_and_calibration.ipynb): metrics at the validation threshold, ROC/DET curves, operating points, errors by generator, attack, language, duration and speaker, calibration, onset check
  - [`03_configurations_and_sweeps.ipynb`](notebooks/Milestone-5/03_configurations_and_sweeps.ipynb): Holm correction of the sweep comparisons, seed spread, default vs final config, sweep checkpoints on test
  - [`error_analysis.ipynb`](notebooks/Milestone-5/error_analysis.ipynb): qualitative results, threshold transfer, quiet-frame analysis, full-set onset check
- **Results:** per-clip scores on the full test sets in `results/<run>/predictions_full.csv.gz` and metrics in `results_full.json`; summary tables in `results/milestone5_*.csv`.

**To reproduce the evaluation:**

1. `pip install -r requirements.txt`
2. Get the weights from the Hugging Face release, and the audio by rebuilding it with the data notebooks of Milestones 4 and 5 (or ask for access to the Kaggle dataset `dsai-group3-m4-data`, version 4).
3. Score: `python -m src.score F-01 --full --data <data folder> [<folder with the full English sets>] --checkpoints <folder with F-01/best.pt> --out <output folder>` (about 46 min on 2 × T4), or push a script from [`kaggle/m5-scoring/`](kaggle/m5-scoring/).
4. Run the Milestone-5 notebooks on the saved predictions (CPU only).
5. Tests: `python -m unittest discover -s tests -p 'test_*.py'`

## Milestone 4: Model Training

- **Report:** [Milestone-4.md](milestones/Milestone-4/Milestone-4.md) · [Presentation](milestones/Milestone-4/Milestone-4-presentation.pdf) · [Worklog](milestones/Milestone-4/worklog.md)
- **Notebooks** (saved with their outputs):
  - [`01_data_preparation.ipynb`](notebooks/Milestone-4/01_data_preparation.ipynb): training and validation data, tuning subset, manifest and leakage checks
  - [`01b_test_data.ipynb`](notebooks/Milestone-4/01b_test_data.ipynb): the five test sets and their Milestone-4 sample
  - [`01c_click_fix.ipynb`](notebooks/Milestone-4/01c_click_fix.ipynb): finds and removes the click at the start of real Kathbath clips
  - [`02_training.ipynb`](notebooks/Milestone-4/02_training.ipynb): runs a queue of training runs on Kaggle, one config each
  - [`03_training_and_evaluation.ipynb`](notebooks/Milestone-4/03_training_and_evaluation.ipynb): baselines, hyperparameter experiments, augmentation, comparisons, metrics and sample outputs
- **Runs:** one config per run in [`configs/`](configs/), and its logs, predictions and metrics in [`results/`](results/). Model weights stay in the Kaggle notebook that trained each run, linked in its `run.json`.

**To reproduce a run:**

1. `pip install -r requirements.txt`
2. Optional: rebuild the data with `01_data_preparation.ipynb`, `01b_test_data.ipynb` and `01c_click_fix.ipynb`, or ask for access to the Kaggle dataset `dsai-group3-m4-data` (see [`data/README.md`](data/README.md)).
3. Train: `python -m src.train --config configs/F-01.yaml --data <data folder> --out <output folder>`, or run `02_training.ipynb` on Kaggle (GPU T4 × 2, internet on) with `RUN_IDS = ["F-01"]`.
4. Score: `python -m src.score F-01 --data <data folder> --checkpoints <folder with F-01/best.pt> --out <output folder>`, then run `03_training_and_evaluation.ipynb`.
5. Tests: `python -m unittest discover -s tests -p 'test_*.py'`
