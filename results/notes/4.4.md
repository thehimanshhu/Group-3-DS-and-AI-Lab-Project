# 4.4 Augmentation

**Setup.** Sweep protocol: 5,000-clip training subset, 3 epochs, full valid set (3,952 clips), seed 42, git commit `51b7f84`. Baseline T-01c is the default XLS-R config on the click-fixed v3 data: **1.341% valid EER**. Numbers come from `results/V-*/run.json` and `epoch_log.csv`; negative Δ is better.

| Run | Augmentation | Train EER | Valid EER | Δ vs T-01c | Best epoch |
| --- | --- | ---: | ---: | ---: | ---: |
| T-01c | none (default) | 1.200% | 1.341% | — | 3 |
| V-06 | noise + gain | 1.100% | 1.518% | +0.177 pp | 2 |
| V-07 | speed + pitch + reverb | 2.600% | 4.580% | +3.239 pp | 3 |
| V-08 | rawboost | 0.700% | 1.468% | +0.127 pp | 3 |
| V-09 | codec / phone | 0.400% | 0.607% | −0.734 pp | 3 |
| V-10 | all effects | 15.799% | 20.698% | +19.357 pp | 3 |

**Findings.**

- **Codec / phone is the only augmentation that helps.** V-09 reaches 0.607% valid EER, 0.734 pp better than T-01c, and is one of the three best V runs overall. A paired bootstrap over the 3,952 valid clips puts its gain outside the baseline noise (see 4.5).
- **Noise + gain and rawboost are slightly worse than the baseline.** V-06 (1.518%) and V-08 (1.468%) are +0.18 and +0.13 pp from T-01c. These gaps are within single-seed noise, so the result is "no evidence of improvement" rather than proof of harm.
- **Speed + pitch + reverb and all effects together are much worse.** V-07 (4.580%) and V-10 (20.698%) fail at this budget. Both were still improving at epoch 3, so the fixed 3-epoch protocol particularly penalises augmentation that slows convergence.
- **V-10 is not a crashed run.** Train EER falls each epoch (23.2% → 19.4% → 15.8%) and AUC is 0.884, so the model learns. But the scores are strongly biased toward fake (mean `p_fake` 0.73 on a balanced valid set), which points to the combination being too aggressive rather than a broken pipeline.
- **Caveat.** These are single-seed, 3-epoch runs on one valid set. Small differences are noisy, and heavy augmentation should be retested at full length before it is rejected or accepted.

**Implication.** Codec / phone is the only augmentation candidate for the final config. The combined setting should not be used as-is.
