Problem Statment: Automated Road Damage Detection Using Computer Vision

Poor road conditions, including potholes and surface cracks, increase vehicle maintenance costs and create road safety risks. Manual road inspections are time-consuming, expensive, and difficult to scale across large road networks.

This project aims to develop a deep learning system that automatically detects, classifies, and prioritizes road damage from photographs.

The project will use the RDD2022 Road Damage Dataset, which contains 47,420 road images from six countries, including India, with more than 55,000 annotated road damage instances. It covers longitudinal cracks, transverse cracks, alligator cracks, and potholes.

The proposed system will combine:

* YOLO-based object detection and transfer learning.
* Image augmentation to improve performance under different lighting and road conditions.
* Damage prioritization based on predicted damage type, size, and detection confidence.
* A web application for image uploads, detection visualization, and maintenance reporting.

A location-aware reporting feature can be added to map damage hotspots using GPS coordinates captured during image collection.

Evaluation metrics: Precision, recall, mAP@50, mAP@50–95, and inference latency.
